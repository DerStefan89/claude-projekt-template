# 💬 Kommentar-Standard

Jede neue Datei beginnt mit:

```
/**
 * Datei: [Pfad]
 *
 * Zweck: [Was macht diese Datei?]
 *
 * Wird aufgerufen von:
 * - [Pfad]
 *
 * Wichtig:
 * [Was darf nicht leichtfertig geändert werden?]
 */
```

Jede neue Funktion bekommt eine Dokumentationszeile im Stil der Sprache
(JSDoc für TS/JS, NatSpec für Solidity, Docstring für Python):

```
/**
 * [Ein Satz: was die Funktion tut]
 * @param [name] - [Bedeutung]
 * @returns [Bedeutung]
 */
```
